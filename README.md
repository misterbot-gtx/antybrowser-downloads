# Downloads do AntyBrowser

Baixe a versão mais recente do AntyBrowser para o seu sistema operacional.

## Downloads

| Sistema | Arquivo | Como usar |
| --- | --- | --- |
| Windows 64-bit | `AntyBrowser-Setup-1.0.0-x64.exe` | Baixe e execute o instalador. |
| Linux 64-bit | `AntyBrowser-1.0.0-x86_64.AppImage` | Baixe, dê permissão de execução e abra o arquivo. |

Os instaladores estão disponíveis na página de [Releases](../../releases/latest).

## Linux

Após baixar o arquivo `.AppImage`, execute no terminal:

```bash
chmod +x AntyBrowser-1.0.0-x86_64.AppImage
./AntyBrowser-1.0.0-x86_64.AppImage
```

## Atualizações

Sempre baixe novas versões pela página de Releases. Cada versão inclui suas respectivas notas de atualização.

## Segurança

Baixe arquivos somente deste repositório oficial. O Windows pode mostrar um aviso ao abrir uma versão sem certificado de assinatura de código.

## Suporte

Para ajuda, acesse o site do AntyBrowser ou entre em contato com o suporte configurado pelo administrador.
